# Honda Landing Page

A responsive landing page designed to promote Honda motorcycles and connect potential customers directly with a sales representative.

## About

The project focuses on providing a simple and modern experience for customers interested in Honda motorcycles.

Users can fill out a contact form, select a motorcycle model, and send their information directly through WhatsApp.

## Features

* Responsive design for desktop, tablet, and mobile
* Honda motorcycle model selection
* Customer contact form
* WhatsApp integration
* Form validation
* Interactive animations
* Custom favicon
* Clean and modern interface

## Technologies

* HTML5
* CSS3
* JavaScript
* Netlify
